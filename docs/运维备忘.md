# 运维备忘

> JianShanAgent · 实例 · 文档

这个部署是什么样、用了哪些外面的服务、做事时要守的规矩。只写现状：状态变了就改这里，不记流水账，不写计划。怎么发布、回滚、备份恢复，见核心的[部署与运维](https://github.com/JianShanAgent/agent-core/blob/main/docs/部署与运维.md)。

这个仓库是公开的。这台服务器的地址、登录方式这类只和自己有关的东西不写在这里，放在本机的`docs/私有备忘.md`（不入库）。

## 现在的状态

- 整套服务在线。当前是哪个发布：`./release list`。
- 知识库：约 7700 篇文档、1.4 万个切片，图库约 3000 张图；`kbsync` 每小时跟着 wiki 更新一轮。
- 开发机上不要启动连 QQ 的进程：同一个机器人不能两处同时在线。本机调试用 `JIANSHANAGENT_DRY_RUN=1`。

## 服务器

| | |
|---|---|
| 发布、`.env`、凭据 | `/opt/jianshanagent/`：`releases/`、`shared/.env`、`shared/secrets.yaml`、compose 入口 `ctl` |
| 数据 | `/home/jianshanagent/`（单独的数据盘）：`postgres/`、`backups/`、`bot/`、`redis/`、`loki/`、`grafana/`、`alloy/` |
| 备份 | 每天 03:30，保留 14 天；第二份拷到系统盘的 `/opt/jianshanagent/backups/`，留最新 3 份 |
| 管理后台 | 内网地址的 13001 端口（令牌：服务器上 `cat /home/jianshanagent/bot/admin/token`） |
| Grafana | 内网地址的 13000 端口，用户 `admin`，密码在 `shared/.env`；日志的标签是 `job="jianshanagent"` |
| 健康检查 | `http://127.0.0.1:18080/healthz`，只绑本机 |
| 部署插件 | `logs`（`shared/.env` 的 `JIANSHANAGENT_DEPLOY_PLUGINS`） |

管理后台和 Grafana 只绑在内网地址上，不对公网开放。

## 开发机

几个仓库并排放在同一个目录下。本仓库的 `data/`（不入库）里是知识库文件和取数缓存，1.5 G：切片、向量、图库记录、各页面取下来的原始内容。凭据在 `config/secrets.yaml`（不入库），调试覆写在 `config/local/`。

## 用到的外部服务

| 是什么 | 用的是哪家 | 凭据（`secrets.yaml`） | 要知道的 |
|---|---|---|---|
| wiki | 阴阳师 wiki（灰机），<https://yys.huijiwiki.com> | `wiki.authkey` | 站在 Cloudflare 后面，请求要带放行请求头，否则 403 |
| QQ | QQ 开放平台的机器人 | `qq.app_id`、`qq.client_secret` | 被动回复有次数上限；带了平台不认的链接整条消息会被拒 |
| 对话模型 | 小米 MiMo（OpenAI 兼容） | `llm.api_key` | 思考只有开关，`tool_choice` 只支持 auto；思考模式下带工具调用的历史要原样带回思考内容 |
| 嵌入 | 模力方舟的 `Qwen3-VL-Embedding-8B`（4096 维，文字和图片同一个空间） | `gitee_ai` | 库里的向量和它绑定：换提供方或型号，知识库和图库要全部重算 |
| 联网搜索 | 小米 MiMo 的按量付费接口（`api.xiaomimimo.com`），强制联网；搜索每 1000 次 16 元，另算 token | `mimo_search` | 只有查证走到 `web` 那一级才调用。密钥是 `sk-` 开头的那种，和对话模型的 Token Plan 密钥不通用；账号要开通「联网服务插件」。密钥没填时没有这一级 |

## 对 wiki 的规矩

那是别人的生产站点：取数并发不超过 2、每秒不超过 2 个请求（`plugin.knowledge` 的 `fetch`，不要调高）。知识库自动更新没变化的一轮只发 1 个请求；全部重取一次 400 多个请求，只在夜里 03:00–06:00 做。

wiki 数据里已知的毛病（不是机器人的问题）：`Data:603.json` 是「毗沙门天」的游离重复文档；「晴明」的技能列表里「言灵·缚」重复了一次。
